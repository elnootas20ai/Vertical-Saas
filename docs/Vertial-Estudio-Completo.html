Resumen ejecutivo. Vertial es una plataforma SaaS multi-vertical diseñada en España para digitalizar la operativa diaria de pymes y negocios con varios locales: compraventa de vehículos, delivery, restauración, taller, limpieza, construcción, eventos y más de veinte tipos de negocio adicionales. Un mismo motor central (cuentas, permisos, CRM, finanzas, documentos, equipo, TPV, alertas) se adapta a cada vertical sin duplicar sistemas. El producto está desplegado en producción, cuenta con app nativa iOS/Android (Capacitor), landing comercial, programa de afiliados y facturación de suscripción integrada con MONEI.

1. ¿Qué es Vertial?

Vertial se define como «más tiempo, menos tareas, más control»: stock, operaciones, clientes, TPV en tablet y finanzas en una sola plataforma profesional, sin caos de hojas de cálculo, WhatsApp y herramientas sueltas.

Propuesta de valor

  • Un motor, muchas verticales — misma plataforma, distinta operativa según el sector.
  • Datos en tiempo real — dashboard, KPIs, alertas y actividad del día conectados a la base de datos.
  • CRM unificado — clientes, historial y segmentación centralizados.
  • TPV en tablet — caja, consumo de equipo y turnos listos para mostrador o sala.
  • Seguridad europea — RGPD, permisos granulares, backups automáticos de CouchDB.
  • Centro de alertas — push, email e in-app configurables por rol.

Público objetivo

Propietarios, gerentes y administradores de negocios en España y Europa; equipos operativos (trabajadores, repartidores, cocina, técnicos); partners del programa de afiliados; y operadores de TPV en tablet dedicada.

5. Stack tecnológico

Frontend

  • React 18 + TypeScript + Vite 6
  • Tailwind CSS 4, Radix UI, Lucide, Recharts, TipTap, i18next
  • PWA con service worker (desactivado en app nativa para evitar bundles obsoletos)
  • React Router 6 — más de 200 rutas en routes.tsx

Backend

  • Node.js + Express 5 — monolito modular (index.js + routers por dominio)
  • Autenticación JWT + refresh tokens
  • SSE (eventos en tiempo real), webhooks, jobs de backup
  • Logging estructurado con Pino

Base de datos

  • CouchDB 3.x — patrón multi-base con prefijo configurable (vertial-* / urielsaas-* en entornos de desarrollo)
  • Índices Mango + vistas MapReduce; backups automáticos diarios (retención 7 días)

Infraestructura y despliegue

  • VPS Scaleway — Nginx sirve /var/www/vertial/dist y proxy /api → Node (puerto 3000)
  • Scripts: npm run deploy:frontend, deploy:backend, deploy:all
  • Desarrollo local: npm run dev:local → front :3015, API :3001, print bridge :39201

App móvil

  • Capacitor 8 — iOS y Android (com.vertial.app)
  • Plugins: cámara, push (APNs/FCM), Apple Sign-In, impresión ESC/POS térmica
  • Onboarding nativo de 4 pantallas; suscripciones iOS redirigen a web (política App Store)
  • Build iOS vía Codemagic → TestFlight (pendiente ciclo del usuario)

11. Arquitectura de producto (principios)

  • Vertical modular — delivery, restaurant y compraventa tienen fronteras de código y tests de aislamiento (test:verticals).
  • Features Pro conectadas — las funciones de plan superior deben leer datos reales, no solo desbloquear UI vacía.
  • Multi-tenant — usuario → empresas → marcas → puntos de venta; scope URL sincronizado.
  • Roles — propietario, manager, trabajador, super-admin; permisos granulares por módulo.
  • Motores en background — desactivables en desarrollo (BACKGROUND_ENGINES=off) para no saturar CouchDB.

14. Conclusión

Vertial no es un TPV aislado ni un CRM genérico: es una plataforma operativa integral pensada para el tejido empresarial español, con profundidad real en delivery, restauración y compraventa, y extensibilidad hacia decenas de sectores. El proyecto combina producto comercial (landing, planes, afiliados, reuniones), ingeniería de producción (VPS, CouchDB, backups, deploy automatizado) y movilidad nativa (Capacitor, impresión, Apple/Google auth). La base está desplegada y en uso; el foco inmediato es cerrar la experiencia móvil iOS, pulir la capa comercial (contacto, reuniones, Google login) y continuar la especialización por vertical sin romper el núcleo compartido.
