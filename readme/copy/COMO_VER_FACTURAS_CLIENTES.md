## 🎯 RESUMEN RÁPIDO:

1. **CLIC en tarjeta de cliente** → Abre modal
2. **CLIC en pestaña "Facturas"** → Muestra facturas del cliente
3. **Listo!** Ya puedes ver las facturas

---

## 🔍 SI AÚN NO LA VES DESPUÉS DE ABRIR EL MODAL:

1. Asegúrate de hacer **hard refresh**: `Ctrl + Shift + R`
2. Verifica que el modal se haya abierto completamente
3. Busca la pestaña "Facturas" junto a "Notas"
4. Toma screenshot del MODAL (no de la lista) para que pueda ayudarte mejor
