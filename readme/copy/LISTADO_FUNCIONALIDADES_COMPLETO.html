⚠ DECISIONES PENDIENTES CRÍTICAS (Resumen)

  1. Onboarding: ¿Automático al crear empleado? ¿Obligatorio?
  2. Fichajes: Límite días atrás ajustes, Notificar ajuste manual, Bloquear sin documentación
  3. Horarios: Permitir/bloquear exceso horas, Cambio centro mueve horarios
  4. Vacaciones: Bloqueos capacidad, Forzar sin días, Anticipación mínima, Cancelar al inactivar
  5. Consumos/Gastos: Justificante obligatorio, Tamaño máximo archivo, Permitir aprobar sin justificante, Integración nóminas
  6. Documentación: Tamaño máximo archivo (¿10MB? ¿20MB?), Bloquear fichaje sin documentación
  7. Permisos: Autorización adicional roles críticos
  8. Gestoría: API directa, Formato A3 nóminas
  9. Gamificación: Mostrar ranking a trabajadores, Premios automáticos
