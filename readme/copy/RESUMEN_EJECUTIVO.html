🚀 Priorización de Desarrollo

FASE 1 - BASE (4-6 semanas) CRÍTICO

~50 funcionalidades

  • Gestión de empleados (crear, editar, visualizar)
  • Fichajes completos (entrada, salida, ajustes)
  • Documentos (subir, gestionar, aprobar)
  • Sistema de permisos funcionando
  • Notificaciones básicas
FASE 2 - FLAGS Básicos (3-4 semanas) FLAG

~35 funcionalidades

  • FLAG vacations: Solicitar, aprobar, rechazar vacaciones
  • FLAG schedules: Planificación horaria y turnos
FASE 3 - FLAGS Avanzados (3-4 semanas) FLAG

~23 funcionalidades

  • FLAG expenses: Gestión de gastos y reembolsos
  • FLAG consumptions: Consumos internos
  • FLAG onboarding: Proceso de alta automatizado
FASE 4 - Integraciones (2-3 semanas)

~18 funcionalidades

  • FLAG gestoria: Integración con gestoría externa
  • FLAG multicenter: Soporte multicentro
  • FLAG audit: Auditoría de cambios
  • Módulo Informes avanzados

🔒 Sistema de Permisos

Nivel Descripción Ejemplo de permisos
N1 - Básico Permisos propios del trabajador Fichar, ver vacaciones propias, subir documentos
N2 - Intermedio Visualización del equipo Ver equipo, ver fichajes, ver vacaciones equipo
N3 - Avanzado Gestión del equipo Aprobar vacaciones, ajustar fichajes, gestionar horarios
N4 - Administrador Administración completa Editar datos laborales, cambiar roles, dar de baja

⚠️ Arquitectura de permisos (IMPORTANTE)

  • Los permisos SOLO se definen en roles
  • Los usuarios heredan TODOS los permisos del rol
  • NO hay personalización individual
  • Cambiar rol = cambiar TODOS los permisos

✅ Checklist para el Programador

Antes de empezar:

Leer ESPECIFICACION_BACKEND_COMPLETA.html completo
Revisar LISTADO_FUNCIONALIDADES_COMPLETO.html para entender alcance
Confirmar decisiones pendientes con Product Owner
Configurar entorno de desarrollo
Crear esquemas de base de datos
Implementar middleware de autenticación y permisos

Durante el desarrollo:

Usar IDs únicos en commits (ej: feat(EQ-008): ...)
Seguir estructura de request/response documentada
Implementar TODAS las validaciones descritas
Crear tests unitarios para cada endpoint
Documentar cambios o desviaciones del spec
Revisar FLAGS antes de cada implementación

🚨 Decisiones Pendientes Críticas

Categoría Decisión pendiente
Fichajes Límite días atrás para ajustes: ¿7 días? ¿15 días?
Fichajes ¿Notificar al trabajador ajuste manual del gerente?
Vacaciones Anticipación mínima: ¿15 días? ¿30 días?
Gastos Justificante: ¿Obligatorio u opcional?
Documentos Tamaño máximo archivo: ¿10MB? ¿20MB?
Onboarding ¿Enviar invitación automática al crear empleado?
Gestoría ¿Qué software de gestoría? ¿A3? ¿Sage?
