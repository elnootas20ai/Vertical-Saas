Instalación rápida (2 minutos)

    
1. Añade el contenedor donde quieras mostrar el catálogo:

    
<div id="mi-catalogo"></div>


    
2. Carga el widget con tu API key:

    
<script
  src="https://vertialapp.com/sdk/udar-widget.js"
  data-api-key="udar_sk_xxxxxxxxxxxxxxxx"
  data-container="#mi-catalogo"
  data-theme="light"
  data-per-page="12"
></script>


    

      💡 Genera tu API key en Vertial → Ajustes → API Tokens. Solo necesitas el permiso vehicles:read.

Integración JavaScript avanzada

    
Manejar el clic en un vehículo:

    
// Opción A: función global (data-on-click="abrirModal")
function abrirModal(vehiculo) {
  console.log('Vehículo seleccionado:', vehiculo);
  document.getElementById('modal-titulo').textContent =
    vehiculo.brand + ' ' + vehiculo.model;
  document.getElementById('modal').style.display = 'block';
}

// Opción B: evento DOM
document.getElementById('mi-catalogo').addEventListener(
  'udar:vehicle-click',
  (e) => {
    const vehiculo = e.detail.vehicle;
    window.location.href = '/vehiculos/' + vehiculo._id;
  }
);

// API pública del widget
VertialWidget.refresh();          // Recargar stock desde la API
VertialWidget.setTheme('dark');   // Cambiar tema
VertialWidget.getVehicles();      // Obtener array de vehículos


    
Verificar firma HMAC de webhooks (Node.js):

    
// Verificar que el webhook viene de Vertial
import crypto from 'crypto';

function verificarFirma(secret, body, signatureHeader) {
  const [tPart, vPart] = signatureHeader.split(',');
  const ts = tPart.replace('t=', '');
  const expectedSig = crypto
    .createHmac('sha256', secret)
    .update(`${ts}.${body}`)
    .digest('hex');
  return vPart === `v1=${expectedSig}`;
}

// En tu servidor n8n / Express:
app.post('/webhook/udar', (req, res) => {
  const sig = req.headers['x-udar-signature'];
  const raw = JSON.stringify(req.body);
  if (!verificarFirma(process.env.WEBHOOK_SECRET, raw, sig)) {
    return res.status(401).send('Firma inválida');
  }
  const { event, data } = req.body;
  console.log('Evento recibido:', event, data);
  res.sendStatus(200);
});
